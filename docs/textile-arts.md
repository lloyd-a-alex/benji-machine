# Textile Arts — Reference

KNITCAT is a knitting-machine CAD, but a knit loop and a woven interlacement share the
same ancestor: a rectangular grid that says *up or down* at every crossing. The **Weave
Structures** family in the pattern library (and the *Textile Heritage* dock) encode the
woven half of that heritage. This file keeps the source taxonomy in plain text so it is
searchable in the repo and independent of the running app.

Everything below is drawn from the public-domain *Textile arts* / *Textile designers*
navigation taxonomy.
